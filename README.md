# 🤖 From Prompt to Post – Agentic AI for Social Media Automation

🚀 Built during the **"From LLMs to Agentic AI" Hackathon** organized by **Utopia x KRYPTOSPHERE®**, mentored by **NVIDIA, AWS, Mistral AI, and Google Cloud**.

## 🧠 Overview

This project explores how **autonomous agents** can solve real-world business challenges by going beyond traditional LLMs and leveraging the power of **Agentic AI**.

We developed a **full-stack platform** that automates the entire pipeline of creating and publishing business content on social media — from a single user prompt to a multi-platform, multimedia post.

---

## 💡 What It Does

- Takes a **single user prompt**
- Enriches it using **RAG (Retrieval-Augmented Generation)**
- Uses the **Mistral AI API** to generate a custom script
- Enhances user-provided images
- Generates visuals and audio
- Compiles everything into videos and images
- Stores content via **AWS (S3, EC2, CloudFront)**
- Automatically schedules and publishes posts on **LinkedIn, Instagram, TikTok**, and more

---

## 🛠️ Tech Stack

| Layer        | Tech Used                                     |
|--------------|-----------------------------------------------|
| 🧠 AI Models| Mistral AI, Retrieval-Augmented Generation     |
| ☁️ Backend  | AWS EC2, S3, CloudFront, Python                |
| 🎨 Media    | Image enhancement, FFmpeg for video rendering  |
| 🌐 Frontend | Streamlit                                      |
| 🔌 APIs     | LinkedIn API, Instagram Graph API, TikTok API  |

---

## 🧱 Architecture

Each **autonomous agent** is hosted on a dedicated **AWS virtual machine**, providing:

- ⚙️ Scalable deployment  
- 🧩 Modular architecture  
- 🔐 Secure, isolated execution environments

---

## 📦 Features

- 🔁 Fully automated content pipeline  
- 📅 Smart scheduling with optimized timing  
- 🎥 Video and image generation from enhanced images and audio  
- 🔒 Cloud-based storage and delivery via AWS  
- 🌐 Multi-platform social media integration
